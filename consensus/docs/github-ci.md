# Tidecoin Fixture Provenance

This crate no longer uses the old upstream `script_assets_test_minimizer`
pipeline as its active parity/provenance workflow.

The active Tidecoin-native proof surface is:
- direct node-fixture replay from `TIDECOIN_NODE_REPO/src/test/data`
- pinned fixture hashes in
  [tests/tidecoin_fixture_hashes.rs](/home/yaroslav/dev/tidecoin/rust-tidecoin/consensus/tests/tidecoin_fixture_hashes.rs)
- generated large-corpus monotonicity from `tx_valid_pq.json` and
  `tx_invalid_pq.json` in
  [tests/tidecoin_script_assets_generated.rs](/home/yaroslav/dev/tidecoin/rust-tidecoin/consensus/tests/tidecoin_script_assets_generated.rs)

## Generated Large-Corpus Metadata

The generated script-assets corpus is pinned by:
- [tests/data/tidecoin_script_assets_generated_metadata.json](/home/yaroslav/dev/tidecoin/rust-tidecoin/consensus/tests/data/tidecoin_script_assets_generated_metadata.json)

Required metadata keys:
- `source_node_commit`
- `source_generation`
- `source_fixtures.tx_valid_pq_sha256`
- `source_fixtures.tx_invalid_pq_sha256`
- `generated_case_count`
- `generated_sha256`

The metadata is generated by:
- [scripts/generate_tidecoin_script_assets_generated_metadata.py](/home/yaroslav/dev/tidecoin/rust-tidecoin/consensus/scripts/generate_tidecoin_script_assets_generated_metadata.py)

## Refresh Workflow

1. Export the generated large corpus from the active node fixtures:
```bash
mkdir -p /tmp/tidecoin_script_assets
TIDECOIN_NODE_REPO=/path/to/tidecoin \
TIDECOIN_SCRIPT_ASSETS_WRITE_GENERATED_JSON=/tmp/tidecoin_script_assets/generated.json \
cargo test -p consensus --test tidecoin_script_assets_generated tidecoin_generated_script_assets_monotonicity -- --nocapture
```

2. Regenerate the provenance metadata:
```bash
python3 scripts/generate_tidecoin_script_assets_generated_metadata.py \
  --json /tmp/tidecoin_script_assets/generated.json \
  --tx-valid /path/to/tidecoin/src/test/data/tx_valid_pq.json \
  --tx-invalid /path/to/tidecoin/src/test/data/tx_invalid_pq.json \
  --node-repo /path/to/tidecoin \
  --output tests/data/tidecoin_script_assets_generated_metadata.json
```

3. Validate the generated-corpus proof surface:
```bash
TIDECOIN_NODE_REPO=/path/to/tidecoin \
cargo test -p consensus \
  --test tidecoin_script_assets \
  --test tidecoin_script_assets_generated \
  --test tidecoin_fixture_hashes \
  -- --nocapture
```

## Historical Note
