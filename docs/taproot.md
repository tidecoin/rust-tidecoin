# Taproot

Taproot is not part of Tidecoin's intended supported surface.

The current direction is to keep the codebase focused on the non-Taproot transaction, address,
and key paths used by the Tidecoin network. Any legacy Taproot code that remains in the tree should
be treated as internal residue, not as a feature to extend or document further.

If Taproot support ever becomes relevant again, it should come back through a dedicated design and
validation pass rather than by expanding the current legacy code.
