# Archived Upstream Logo Material

The files in this directory are archived upstream Rust Bitcoin logo assets. They are retained only
for provenance and are not active Tidecoin branding.

## Files

- `rust-bitcoin-inkscape.svg` - upstream Inkscape source asset.
- `rust-bitcoin-optimized.svg` - upstream optimized SVG asset.
- `rust-bitcoin.png` - upstream 300px PNG render.
- `rust-bitcoin-large.png` - upstream 1024px PNG render.

## Provenance

The original artwork was authored by Hunter Trujillo. The archived assets combine public-domain
Bitcoin logo material with Rust logo material under Rust project media guidelines.
